The main-only job's effective token has `Actions: read`; the same endpoint and expected rc254 identity are readable with the existing owner CLI. The response status inside the failed job is not exposed by the no-leak adapter, so the exact API failure cause remains unconfirmed.

The fallback reads the official log archive for **the same exact successful QA run** only when the per-job API call fails. It accepts one bounded detector log, rejects duplicate or malformed archive entries, and applies the unchanged exact rc254 identity check. A mismatching per-job log is not eligible for fallback. The final QA artifact, digest, source/base, activated policy, review expiry, and latest-check checks are unchanged.

The existing run archive for #712 QA 43185919922 is 180853 bytes and contains one detector log with the exact rc254 source. Local parser and adversarial tests pass. This is source preparation only; it does not prove the workflow token can read the run archive.
